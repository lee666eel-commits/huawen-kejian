# 华文互动课件

林子策（Lim Zi Ce）设计的华文课堂互动练习，单文件 HTML，手机、电脑打开即用。

**直接使用：** https://lee666eel-commits.github.io/huawen-kejian/

| 课件 | 说明 |
|---|---|
| [种梨·梨市三岔路](https://lee666eel-commits.github.io/huawen-kejian/种梨.html) | 蒲松龄《种梨》初三统考复习：五回剧情里选当卖梨人、旁观者还是道士；课本 38 条注释点读、每回一句翻译练习、仿统考课内文言 6% 实战、注释抽卡。 |
| [应用文四类辨析](https://lee666eel-commits.github.io/huawen-kejian/应用文四类辨析.html) | 读句子，判断属于活动宗旨、通告目的、活动详情还是事件描述。页面内可改题并导出。 |
